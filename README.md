# AI Document Q&A

Chat with any PDF using a Streamlit app powered by Gemini, ChromaDB, and sentence-transformers.

## Live Demo

https://ai-document-app-pkp.streamlit.app/

## Features

- Upload PDF documents
- Extract and chunk document text
- Store embeddings in ChromaDB
- Ask natural language questions about the uploaded document
- Get context-aware answers generated by Gemini

## Tech Stack

- Python
- Streamlit
- Google GenAI (Gemini)
- PyPDF2
- ChromaDB
- Sentence Transformers

## Project Structure

```
.
├── app.py
└── requirements.txt
```

## Setup

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Set your Gemini API key:

```bash
export GEMINI_API_KEY="your_api_key"
```

## Run Locally

```bash
streamlit run app.py
```

Then open the local URL shown in your terminal.

## How to Use

1. Upload a PDF file.
2. Wait for document processing to complete.
3. Ask questions in the chat box.
4. Review answers generated from relevant document context.
